# 02 — Base de Conhecimento do FinGuide

## Objetivo

A base de conhecimento define quais informações o FinGuide pode usar para responder.

## Arquivos

- `orcamento.json`
- `credito.json`
- `dividas.json`
- `planejamento.json`
- `seguranca.json`
- `faq.json`

## Funcionamento

A aplicação deverá identificar termos relevantes na pergunta, recuperar os registros relacionados e enviar esse contexto ao modelo de linguagem.

## Regras

1. Não armazenar taxas atuais sem fonte dinâmica.
2. Não inventar dados ausentes.
3. Priorizar conceitos educacionais estáveis.
4. Manter os registros pequenos e objetivos.
5. Utilizar palavras-chave para facilitar a recuperação.
6. Quando uma decisão depender do contexto pessoal, apresentar critérios em vez de uma resposta absoluta.

## Referências

A estrutura utiliza como referência conteúdos de educação financeira e segurança do Banco Central do Brasil.

## Limitação

A base é educacional e não substitui informações oficiais atualizadas nem orientação financeira profissional individualizada.
